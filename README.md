## 🏗️ Repository Architecture
The project is organized into a modular, level-based hierarchy to ensure a rigorous progression of skills:

### 📂 [01_Basics](https://github.com)
Focuses on the bedrock of Python programming.
- **Variables & Data Types:** Understanding memory allocation and primitive types.
- **Arithmetic Logic:** Implementing mathematical formulas for early algorithm development.
- **Control Flow:** Mastery of `if-else` branching and basic `for/while` loops.

### 📂 [02_Intermediate](https://github.com)
Transitions into interactive and dynamic programming.
- **User Input Handling:** Developing robust interfaces for data ingestion.
- **Integer Conversion:** Managing type-casting and data integrity during runtime.
- **Data Structures:** Early implementation of Lists, Tuples, and Dictionaries.

### 📂 [03_Advanced](https://github.com)
Focuses on software design patterns and modularity.
- **Functional Programming:** Writing reusable, clean code using advanced functions.
- **OOP Principles:** Implementing Classes and Inheritance for scalable systems.
- **Decorators & Generators:** Optimizing memory usage and function behavior.

### 📂 [04_Expert](https://github.com)
The bridge to Artificial Intelligence and Systems Engineering.
- **Error Handling:** Implementing Level 13 `try/except` blocks for fault-tolerant applications.
- **GPU Computing:** Utilizing `gpu_check.py` to verify CUDA cores and VRAM availability.
- **Hardware Interfacing:** Leveraging WSL2 and Linux environments for native performance.
